# 0010 站点动效、光标、市场目录和排行榜

- 状态：实现中（2026-11-07）。
- 用户的要求（2026-11-07）：继续优化动效和细节——滚动到下面时左边要有动效出现对应的分类列表；站点的鼠标样式；各个页面的整体设计感；收集的条目太少，要多收；要有排行榜。设计按站里的 `motif-design` skill 来。

## 1. 动效身份

按 `skills/motif-design/references/motion.md` 选一种性格并全站统一：**安静、高级**（夜间画廊）。

- 缓动：进入用 `--ease-out-soft`（`cubic-bezier(0.22, 1, 0.36, 1)`，已有），离开用 `--ease-in-soft`（`cubic-bezier(0.5, 0, 0.75, 0)`），两个位置之间移动用 `--ease-in-out-soft`。
- 时长三档：`--duration-fast` 150ms（悬停、按下、开关）、`--duration-base` 240ms（菜单、面板、卡片）、`--duration-slow` 420ms（页面切换、共享元素）。离开比进入短 20–30%。
- 全部写成 `globals.css` 里的 token，组件里不再散落数字。
- **唯一的「大动作」**：从卡片进入条目页时，海报变形成详情页的预览（共享元素过渡，React `<ViewTransition>`，Next 16 自带）。告诉用户「点开的就是这一个」。
- 不做的事（反 AI 味清单）：滚动时每个区块淡入上移、卡片悬停抬起加阴影、按钮无限脉冲、文字视差。
- 「减少动态效果」：页面切换变成瞬间切换，侧栏、光标不做位移动画，只保留颜色和透明度的变化。

## 2. 市场：按分类分组 + 滚动出现的分类侧栏

- 没有搜索词、按「精选」或「热门」排序、没开「只看收藏」、没选具体分类时，市场按**层级 → 分类**分组展示（全部时最前面加一组「精选」）；其余情况（搜索、最新、收藏、单个分类）保持平铺网格。
- **宽屏（≥1024px）**：左侧一栏是目录。页面顶部筛选栏还在视口里时，目录只列层级（安静的状态）；筛选栏滚出视口后，目录「接手」导航：当前层级展开出它的分类（高度 0fr → 1fr，分类逐个淡入，间隔 30ms），当前分类有一条滑动的指示线（随滚动在分类之间移动）。点分类平滑滚到那一组。
  - 这个动画说明一件事：顶部的分类没有消失，它们换到了左边，并且在跟踪你看到哪儿了。
- **窄屏**：筛选栏滚出视口后，头部下方滑出一条吸顶的分类条（横向滚动的小标签），当前分类高亮并自动滚进视野；滚回顶部时收起。
- **性能**：分组后全部条目都在一页上。每组先渲染和真卡片同样排版的骨架（纯 div，没有状态），组离视口 1200px 内才换成真卡片（和原来分批渲染的理由一样：上百张卡片一次性水合，首屏的第一次点击要等很久）。骨架和卡片排版完全相同，点目录跳到很远的组也不会错位。
- 滚动监听：只在滚动时用 rAF 读一次各组的位置（几十个元素），不用每组一个 IntersectionObserver。

## 3. 鼠标样式

- 只在**精确指针 + 可悬停**的设备上启用（`(pointer: fine) and (hover: hover)`），触屏不变；页脚有开关，存在这个浏览器里。
- 开启「减少动态效果」时照样启用（很多人关掉系统动画只是为了快，光标的形态本身就是信息），但细圈直接贴着指针、变形没有过渡：去掉运动，保留含义。
- 形态：一个 6px 实心点精确跟随指针（不滞后，保证点得准），外加一个 28px 细圈用弹簧跟随（`visualDuration 0.25, bounce 0`）。用 `mix-blend-mode: difference`，在深浅主题、海报上都看得见。
- 状态（用事件委托在 `pointerover` 里判断，元素可以用 `data-cursor` 指定）：
  | 指在 | 光标 | 说明 |
  | --- | --- | --- |
  | 链接、按钮、可点的标签 | 圈放大成 44px、半透明填充，点隐去 | 「可以点」 |
  | 市场卡片（`data-cursor="view"`） | 圈变成带字的胶囊「查看」 | 「点开看详情」 |
  | 段落、标题等文字 | 圈收成 2×20px 的竖线 | 保留「可以选中文字」的提示 |
  | 输入框、可编辑区域 | 自定义光标隐藏，用系统的插入符 | 打字时不能遮挡 |
  | iframe（预览沙箱） | 自定义光标隐藏 | 指针进了别的文档，跟不过去 |
  | 按下 | 圈缩到 0.85 | 按下的反馈 |
- 只在指针移动、或者圈还没追上时跑 rAF；只改 `transform`。

## 4. 排行榜

### 统计什么

只统计真实使用，不造数据：

| 事件 | 来源 | 去重 |
| --- | --- | --- |
| 浏览 `view` | 条目详情页打开（浏览器发一次） | 同一访客同一条目每天一次 |
| 复制 `copy` | 复制安装命令、代码、Skill | 同上 |
| 收藏 `favorite` | 收藏 +1、取消 −1 | 每个方向每天一次 |
| 拿走 `take` | shadcn 安装（`/r/<slug>.json`）、下载 zip、积分解锁、MCP 交付 | 同上 |
| 改编 `remix` | 在工作台打开、fork 成仓库 | 同上 |

- 访客 = `HMAC(站点密钥, 日期 + IP)` 和 `HMAC(站点密钥, 日期 + IP + UA)` 两段哈希：每天换盐，不能还原 IP，不跨天追踪，不用 cookie。去重表只留两天。
- UA 是客户端自己写的：同一个 IP 同一天对同一个条目的同一种操作，最多算 5 个不同的访客。换着 UA 刷不上去，同一个网络（学校、公司）后面的几个人也都能算上。
- 计数存 SQLite：`item_stat_daily(day, slug, event, count)`；去重表 `item_stat_seen(day, slug, event, visitor)`。
- 明显的爬虫（UA 带 bot / spider / crawl / headless）不计。

### 怎么排

- 综合分 = 浏览 × 1 + 复制 × 3 + 收藏 × 4 + 拿走 × 6 + 改编 × 5。「拿走」「改编」权重高：说明真的用上了。
- 时间范围：本周（7 天）、本月（30 天）、全部。和上一个同样长的时间段比，标出名次升降或「新上榜」。
- 榜单：综合、收藏最多、拿走最多；可按层级筛选。
- 统计从 2026-11-07 开始，页面上写明。上榜条目少于 10 个时说明「数据还在积累」，下面接着放没上榜的精选，不用 0 填满。
- 市场多一个「热门」排序（本周综合分），本周前 10 的卡片标名次；条目页显示本周名次。

## 5. 条目扩充

- 从 `sources/sources.json` 里已登记的 A 级来源继续移植（magicui、motion-primitives、kokonutui、cult-ui、animata、smoothui、eldoraui），优先补薄弱的分类：文字效果、光标、按钮、卡片、背景、数据展示。
- 标准不变（`docs/authoring-items.md`）：许可证头、provenance、5–10 个参数、3–5 个预设、默认值最好看、`pnpm audit:items` 和 `pnpm capture` 的闸门全过，海报亲眼看过。
- 这一版新增 30 个（共 175 个）：文字效果 7、背景 6、光标 2、按钮 5、卡片 3、功能组件 7（数据、布局、导航、弹窗、进度、输入）。其中 4 个进了精选（`apps/web/src/lib/featured.ts`）。
- 和已有条目重复的没收（例如文字微光波之于「微光文字」加载动画、发光边框之于边框光束），换成了同一来源里别的组件；上游依赖了不允许的包时自己重写（金属环按钮），在 provenance 里写明。
- 截图工具顺带修了两个问题：
  - 「减少动态效果」那一轮做完要显式切回 `no-preference`：在 Edge 上传 `null` 不会撤销模拟，后面录的循环视频会变成静止画面（`scripts/capture.ts`）。
  - 手动时钟下，走到终点的有限动画要调用 `finish()`：暂停状态的动画不会触发 finished，motion 的退场（`AnimatePresence`）会一直等，下一个元素永远不出现（`apps/preview/src/runtime/clock.ts`）。
